# oyster-cursor

Hosts the 3D oyster-shell model used by the custom 3D cursor on my website.
Model: `SM_OysterShell.glb` (from Billion Oyster Project materials).
Served via jsDelivr: https://cdn.jsdelivr.net/gh/WeiWu0115/oyster-cursor@main/SM_OysterShell.glb

Static cursor PNGs (rendered from the same model) for plain CSS `cursor:` use:
`oyster-cursor.png` (32px), `oyster-cursor-hover.png` (40px), plus `@2x` versions.
